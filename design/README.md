# Art reference

`Tether Art Reference.dc.html` is the visual spec of record, exported from
Claude Design. It is the source for the sky ladder, planet layer stack, ring
tick language, hazard geometry, boss build, skin table and background layers now
implemented in `index.html`.

It will not *render* standalone — it was authored against the Claude Design
runtime (`support.js`), which is not vendored here. Read it as source: every
dimension, ratio and colour is written out in the markup and in the drawing
methods at the bottom of the file.

Where the implementation departs from the sheet, it is noted in `REVIEW.md`.
